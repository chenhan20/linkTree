Goofy Uploader 隱私權政策

生效日期：2026 年 10 月 27 日

這是什麼

Goofy Uploader 是 YouTube 頻道 Goofy Intelligence 擁有者自己使用的上傳工具。它在擁有者的電腦上執行，透過 YouTube API 服務把擁有者自己製作的影片上傳到自己的頻道。 它不對外提供服務，沒有其他使用者。

會用到的資料

  • Google 帳戶授權（YouTube 上傳權限 youtube.upload）：只用來上傳影片到擁有者自己的頻道。
  • 擁有者自己選的影片檔，以及標題、說明、標籤、隱私狀態、排程時間等影片資訊。

授權憑證只存在擁有者自己的電腦上，不會傳到任何其他伺服器。Goofy Uploader 不收集、不儲存、不出售、不分享任何人的個人資料， 也不用於廣告或分析。

Google API 服務

Goofy Uploader 使用 YouTube API 服務。使用時即表示同意 YouTube 服務條款 與 Google 隱私權政策。 Goofy Uploader 對 Google API 所取得資訊的使用與傳輸，遵守 Google API 服務使用者資料政策，包含「限制使用」規定。

撤銷存取權

隨時可以到 Google 帳戶的第三方存取權頁面 移除 Goofy Uploader 的權限，或到 Google 安全性設定撤銷。 撤銷後，存在本機的授權憑證會失效。

聯絡

有任何問題，請透過 YouTube 頻道 Goofy Intelligence 聯絡。

Goofy Uploader Privacy Policy

Effective date: October 27, 2026

What it is

Goofy Uploader is a personal upload tool used only by the owner of the YouTube channel Goofy Intelligence. It runs on the owner's own computer and uses YouTube API Services to upload videos the owner made to the owner's own channel. It is not offered to anyone else.

Data it uses

  • Google account authorization with the YouTube upload scope (youtube.upload), used only to upload videos to the owner's own channel.
  • The video files the owner selects, and their title, description, tags, privacy status and scheduled publish time.

OAuth credentials are stored only on the owner's computer and are never sent to any other server. Goofy Uploader does not collect, store, sell or share anyone's personal data, and does not use any data for advertising or analytics.

Google API Services

Goofy Uploader uses YouTube API Services. By using it you agree to the YouTube Terms of Service and the Google Privacy Policy. Goofy Uploader's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time on the Google Account third-party access page or the Google security settings page. Revoking it invalidates the credentials stored on the owner's computer.

Contact

For any questions, contact us through the YouTube channel Goofy Intelligence.

# Surface brief — strava_helicorder.html

第四個視覺世界。`strava.html`（深空觀測站）、`strava_pitwall.html`（維修站牆）、
`strava_opus5_max.html`（遙測 OPUS MAX）都不動。

## Scope & mode

**Operate.** 使用者完成任務：判斷這次表現在歷史裡的位置、決定下次練什麼。
與另外三版同源同資料（`data/*.json`），但視覺世界完全獨立。

## Chosen direction — 記震紙 The Helicorder

方向骰 seed `084721a6`，scope `direction`，mode `operate`，指派 index 6
（我方依共鳴度排序的第 6 項）。使用者於 2026-07-27 核定 `assigned`，無 steer。

**為什麼這個形式承載得住產品**（不是套皮，是結構對得上）：

| 產品機制 | 記震紙原制 |
|---|---|
| 一年的活動時間序列 | 連續紀錄：安靜的底噪 ＋ 突起的事件 |
| 功率 PR（5s…60m 各時距最大值） | 反應譜：不同週期下的最大反應 |
| 同一 ITT 路段反覆挑戰 | 重複地震：同一斷層面反覆破裂，疊起來看漂移 |
| 24/133 筆騎乘無功率 | 測站斷訊：目錄上一律標記，不補零 |
| 月度目標與本週任務 | 測站運轉率／班表 |

**世界**：淡青灰製圖紙（`#DCE2D5`）、鏽紅印格、墨跡線。全頁單一等寬字，
`tabular-nums`。零發光、零圓角、零陰影、零漸層 —— 層級只靠 1px 印線與留白。
**負片模式**是同一份紀錄的微縮膠捲存檔（墨與底互換），不是另一套設計；
夜間手機使用是主要情境，所以它不是裝飾功能。

**四色逐列輪替（墨黑／鏽紅／普魯士藍／橄欖綠）只為分列，不帶意義** ——
這是記震紙原制，圖例上明說。語意墨另外四支，各綁死一個維度：
鏽紅＝最高紀錄／PR，普魯士藍＝90 天內最佳，橄欖綠＝達標，灰＝測站無資料。
**兩套色絕不混用**：語意色永遠不出現在記震紙上，記震紙的事件標記靠形狀
（方＝PR、菱＝90 天內最佳、空心圈＝缺功率、實心圈＝一般）。

## 簽名互動 — 通道選擇器

`時數 BHT / 里程 BHD / 訓練負荷 BHL`。換通道會讓**資料缺口實體浮現**：
切到訓練負荷，24 趟沒有功率計的騎乘從波形塌成空心方框。

**兩種「沒有數字」必須分開，這是本頁的立場**：
- `applies=false` → 該量對該類事件本來就不存在（重訓沒有里程）。**不標記、不算缺值。**
- `applies=true` 但值為 `null` → 該測的沒測到。**標記為缺讀數。**
- **讀數 0 是讀數，不是缺值**（0.1 小時的騎乘 TSS 就是 0）。曾經寫錯過一次，
  把 0 併進缺值，數字變成 26/133；改對之後是 24/133，與 PRODUCT.md 記錄的事實一致。

## 波形是包絡繪法（已在圖例明說）

包絡高度＝當日該通道合計值（真資料）；震盪載波是記震紙的記法，不是額外資料。
每段波包先合成再整段正規化到目標振幅 —— 這樣「最大的一天剛好滿格」是保證的，
不用去猜包絡與載波的相位會在哪裡相乘出峰值。
最大偏擺 `RH × 0.86` **刻意大於半個列高**：夠大的事件本來就會壓過鄰列基線，
這是這種紙的特徵，也正是「那天很硬」一眼看得出來的原因。
種子固定（年月），重新整理不會變形。

## Constraints（本表面）

- 資料一律讀 `data/*.json`，前端不呼叫 Strava API。
- 無 build step、無 webfont、無框架、CSS/JS 全 inline（見 PRODUCT.md）。
- 狀態判定沿用既有 `segScore = powerScore × 0.7 + timeScore × 0.3`，
  基準線取 90 天內功率前 5 名平均，不足 3 筆改用全期 —— 與另外三版一致，
  不另立一套。狀態英文詞（NEW/BREAKTHROUGH/HEATING UP/UNTOUCHED/PEAK/
  RISING/HOLD/DECLINING）是使用者既有詞彙，不得改寫。**emoji 拿掉** ——
  繪圖紙上放 emoji 就是 cosplay，狀態靠字與語意墨分。

## 涵蓋範圍（使用者 2026-07-27 決定）

全 7 節：記震紙、觀測摘要、反應譜、重複事件、觀測班表、月報、事件目錄。
**3D 軌跡回放、每日一句、對手 PK 面板不做** —— 3D 場景是暖橘發光的太空語彙，
硬塞進紙本世界會是全頁唯一一塊對不起來的東西。要看 3D 就回另外三版。

## 失敗長相

1. 堆滿地震裝飾（震央圖示、規模警報、紅黃綠告警燈）—— 形式對了但變 cosplay
2. 為了畫面乾淨而拿掉數據 —— 密度是給主要使用者的價值本身
3. 把 0 當缺值，或把「不適用」當缺值 —— 這頁的立場就是這個，弄錯就沒有立場了

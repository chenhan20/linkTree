## 3. 動作圖書館（影片關鍵字）

**怎麼挑影片**：選 60～90 秒、有**側面角度**、只有講解沒有配樂的；
避開「30 天挑戰」「一週練出腹肌」那種。英文關鍵字找到的技術影片品質明顯比中文高。

### 熱身

| 動作 | 搜尋關鍵字 | 影片要看到什麼／你會做錯的地方 |
|---|---|---|
| 90/90 髖旋轉 | [`90/90 hip switch`](https://www.youtube.com/results?search_query=90+90+hip+switch) | 兩腳都貼地、上半身挺直。**錯**：靠手撐地把身體甩過去 |
| 踝背屈前後搖 | [`deep squat ankle rocks`](https://www.youtube.com/results?search_query=deep+squat+ankle+rocks) | **腳跟全程不離地**，膝蓋往腳尖前方推。這是落地緩衝與踩踏踝角的共同基礎 |
| 臀橋 | [`glute bridge`](https://www.youtube.com/results?search_query=glute+bridge+form) | 用夾臀推起。**錯**：用腰拱起來（腰會痠就是做錯了） |
| Bird dog | [`bird dog exercise`](https://www.youtube.com/results?search_query=bird+dog+exercise+form) | 骨盆不動。背上放個水瓶不掉才算合格 |
| 肩胛伏地挺身 | [`scapular push up`](https://www.youtube.com/results?search_query=scapular+push+up) | **手肘全程打直**，只有肩胛在推開與收攏 |
| 俯臥手臂畫圓 | [`prone arm circles`](https://www.youtube.com/results?search_query=prone+arm+circles+shoulder) | 手臂離地畫大圈，額頭貼墊 |

### 下肢

| 動作 | 搜尋關鍵字 | 影片要看到什麼／你會做錯的地方 |
|---|---|---|
| 分腿蹲（等長） | [`split squat isometric hold`](https://www.youtube.com/results?search_query=split+squat+isometric+hold) | 後腳跟提起、重心壓**前腳**、上身微前傾。**錯**：重心留在後腳＝變成拉筋 |
| 分腿蹲（離心，9/23 後） | [`tempo split squat 3 second`](https://www.youtube.com/results?search_query=tempo+split+squat+3+second+eccentric) | 下降 3 秒、底部 1 秒。**膝蓋輕點地不是砸地**（家裡要安靜） |
| 側弓步 | [`lateral lunge form`](https://www.youtube.com/results?search_query=lateral+lunge+form) | 屈膝腳膝蓋對齊腳尖、另一腿打直、屁股往後坐。**內側出現尖銳拉扯感就停**，那是拉傷前兆 |
| 單腳臀橋 | [`single leg glute bridge`](https://www.youtube.com/results?search_query=single+leg+glute+bridge) | 骨盆兩側等高。**錯**：非支撐側骨盆掉下去 |
| 長槓桿臀橋（等長） | [`long lever glute bridge hold`](https://www.youtube.com/results?search_query=long+lever+glute+bridge+hold) | 腳跟往前放遠、腳尖翹起、**只用腳跟撐**。腿後側要有明顯緊繃感；抽筋就把腳跟收近一點 |
| Hamstring walkout（9/23 後） | [`hamstring walkout`](https://www.youtube.com/results?search_query=hamstring+walkout+exercise) | 從臀橋位置腳跟慢慢往外走再走回來。**這是全表最容易讓你隔天下不了樓梯的動作**，第一次只做 4 下 |
| 單腳提踵 | [`single leg calf raise`](https://www.youtube.com/results?search_query=single+leg+calf+raise+form) | **慢放 2 秒**，下放那一段才是阿基里斯在練。扶牆保持平衡沒關係 |

## 4. 為什麼是這些動作

| 部位／能力 | 誰在練 | 週六 |
|---|---|---|
| 胸、背 | 週三健身房肌力 | 不重複 |
| 跳躍、急停變向 | 週二晚上籃球 1 h | 不重複（家裡也不能跳） |
| 有氧、股四頭耐力 | 週二／四課表、週五日飛輪 | 不重複 |
| **腿後側、內收肌、臀中肌、小腿** | **沒有人** | ✅ 籃球拉傷前三名，單車一輩子不練 |
| **垂直推、後三角、三頭** | 臥推划船都涵蓋不到 | ✅ 線條 |
| **抗旋轉核心** | **沒有人** | ✅ 對抗＋骨盆穩定 |

**為什麼下肢用等長**：等長收縮拿得到力量刺激，但離心損傷極低。
模型實算（新鮮度手動拉到 ×2.0 當上限）：週六早上做 46 分 → 下週二早上 DOMS **11～12**
（判讀門檻 <25 照常），而且 9/08、9/10 都碰不到（0 → 0～1）。
**放週日就不行**，週二會從 8.5 跳到 16.8，而週二是門檻課。

**單車那邊瞄的是什麼**：風櫃嘴逐段分析顯示踏頻 74 → 67、最輕檔佔比 48% → 73%，
**已經在最輕檔退無可退，先掛的是肌肉不是心肺**。那正是這堂課長線要修的東西。

## 5. 三條硬規則

1. **不准拿它換飛輪。** 徒手一分鐘都不進月騎乘時數，飛輪整堂都算，而月時數是 eFTP 的損益線
   （15.3 h／月、斜率 +0.64 W/h）。這堂是**加上去**的。
2. **一定要戴錶錄成肌力訓練。** 不錄的話它在 CTL、DOMS、主觀校準三處都不存在 ——
   跟籃球現在只能靠 `_doms_recurring.json` 佔位是同一個問題。
3. **只排週六早上。** 漏做不補課，尤其不要補到週日或週一。

## 6. 中止條件與校準

模型在這裡是**半瞎的**：`scripts/doms.py` 的新鮮度是用**運動類別**算的，
你 42 天 `lift` 曝光量 227 → ×1.03（「早就習慣重訓了」），
但側弓步、長槓桿臀橋、單腳提踵你一次都沒做過。**你的主觀回報是唯一的校準來源**，
前三週每次做完的隔天早上記一次：

```bash
python3 scripts/doms.py --log 2026-08-30 6 --note "徒手第一週 大腿內側／腿後"
```

（不要因為某一天主觀跟模型對上就當模型被驗證了。）

- 當天早上 DOMS **am ≥ 45** → 下肢整段砍掉，只做上肢＋核心。
- HRV **連兩天低於 52** → 同上。
- 週二熱身騎到第 15 分鐘，同心率下瓦數比上週低 **10 W 以上** → 下個週六下肢每個動作減 1 組。
- 主觀 `--log` 連兩週 **≥ 6/10** → 46 分砍成 30 分（下肢留 1 輪），不要改動作難度。
- 內收肌（側弓步）**尖銳拉扯感 → 立刻停**，那是拉傷前兆不是痠。
- 關節刺痛、麻木、左右明顯失衡或無法維持姿勢 → 立即停止該動作。

## 7. 關於「身體線條」

線條 ＝ **既有肌肉 ÷ 體脂**，主要是廚房問題不是課表問題。
你的數字：PR 期 76.5 kg、現在 **80.0 kg（+4.6%）**，中社逐段分析已經指出這 4.6% 不是騎法能解決的。

但**不要在 9/22 之前製造熱量赤字**。8/25 課表 A 的門檻段只踩出 186／154 W（處方 220–230）、
RPE 只有 6–7、同瓦數心率比常態低 6–8 bpm —— 那已經是恢復不足的簽名。
再疊赤字，9/10 後測與兩趟對照測驗會全部失真，而那是整個區塊唯一的產出。

順序：

1. **現在 → 9/22**：這堂課的工作是「把肌肉留住」，體重不動，睡眠優先。
2. **9/23 起**：開始做體重工程，同時把下肢切到離心版、啟用四週進階。

## 8. 9/23 之後的四週進階

| 週次 | 訓練量 |
|---|---|
| 第 1 週 | 下肢換離心版、2 輪；上肢維持 3 輪 |
| 第 2 週 | 下肢 3 輪 |
| 第 3 週 | 下肢主動作進階一階；維持 3 輪 |
| 第 4 週 | 不加組數；達到次數上限的動作改用較慢節奏或較難版本 |

### 進階順序

- 分腿蹲：標準 → 底部停頓 → 1.5 下 → 保加利亞分腿蹲（後腳放沙發）
- 側弓步：標準 → 底部停頓 → 溜冰者蹲
- 臀橋：雙腳 → 單腳 → 單腳頂端停 3 秒
- 腿後側：長槓桿等長 → Hamstring walkout → 離心北歐腿彎舉
- 提踵：雙腳 → 單腳 → 階梯加深下放 → 單腳停頓 3 秒
- Pike push-up：標準 → 腳墊高 → 停頓
- 棒式：一般 → 長槓桿 → RKC

當所有組都能達到次數上限、而且仍保有指定餘力，才進下一階。
不要把伏地挺身累積到每組 40～50 下 —— 那是耐力不是力量。
